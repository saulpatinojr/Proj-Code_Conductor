# Brand files

The Code Conductor mark is the orchestration graph from `apps/vscode/media/conductor.svg`
(three provider nodes feeding two lanes), rendered on a navy rounded square (`#0B1220`,
nodes `#38BDF8`, lines `#E2E8F0`).

| File | Use |
|---|---|
| `apps/vscode/media/icon.png` (256 px) | the extension icon the Marketplace and VS Code show (`icon` in `apps/vscode/package.json`) |
| `docs/brand/publisher-logo-128.png` | the Marketplace publisher logo (128 px, the form's size) |
| `docs/brand/logo-512.png` | source size for other uses |

All three are rendered from the same drawing at 1024 px and downsampled, so they match.
