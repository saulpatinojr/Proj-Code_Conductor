# Review a Pull Request

Inspect contribution rules, target branch, changed files, requirements, CI, deployment impact, and the diff. Review correctness, failure paths, public compatibility, security, dependencies, authorization, secrets, logging, performance, accessibility, observability, cost, and rollback. Prioritize findings with file evidence, impact, remediation, and confidence. Treat model reviews as advisory. Do not approve, merge, push, dispatch, or publish without explicit authorization. End with a delivery status.
