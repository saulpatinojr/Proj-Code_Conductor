# Build or Review an MCP Server

Identify SDK generation and transport. Define narrow tools, resources, and prompts with precise descriptions, strict input schemas, bounded output, cancellation, timeouts, and explicit errors. Enforce authorization outside model intent and separate read-only from side-effecting operations. Review stdio protocol cleanliness or HTTP origin/auth/session controls. Add malformed-input, oversized-result, authorization, prompt-injection, cancellation, failure, audit, and denial-of-wallet tests. Ask before privileged or externally visible actions.
