# Implement a Feature

Use the repository's conventions and the approved plan. Make the smallest coherent change in reviewable increments. Use strict TypeScript and runtime validation at trust boundaries. Add or update focused unit, contract, integration, browser, security, or regression tests as applicable. Update operational documentation and ADRs when needed. Run narrow checks first, diagnose failures, inspect the final diff for secrets and accidental scope, and report verified versus unverified acceptance criteria.
