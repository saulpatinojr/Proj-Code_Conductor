# Design an Agentic System

Start with a deterministic workflow and introduce autonomy only where adaptation adds value. Define goals, state, context and provenance, tools, schemas, policy checks, approvals, handoffs, termination, step/time/token/cost budgets, cancellation, retries, recovery, evaluation, observability, privacy, and ownership. Prefer one agent before multiple agents. Record important decisions in an ADR and define evidence that can prove completion.
