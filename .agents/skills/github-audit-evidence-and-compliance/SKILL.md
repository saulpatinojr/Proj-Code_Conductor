# Audit, Evidence, and Compliance

Create an evidence ledger with source, timestamp, ref or API endpoint, actor, query, result summary, sensitivity, and verification level. Label each statement CONFIRMED, INFERRED, HYPOTHESIS, or NOT_VERIFIED.

For a readiness decision, cover repository identity, branch and ruleset state, review approvals, status checks, workflow security, deployment environment, security controls, artifact provenance, rollback, ownership, and unresolved exceptions. Capture exact log excerpts only after redaction.

Do not claim live compliance from static files. Do not export audit data, download sensitive logs, or retain secrets without authorization and an approved destination. End with scope, limitations, findings, recommendation, owner, and next evidence request.
