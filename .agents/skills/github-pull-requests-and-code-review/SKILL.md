# Pull Requests and Code Review

Collect base/head refs, merge base, changed files, commits, draft state, authors, requested and completed reviewers, CODEOWNERS, review threads, check runs, deployments, labels, mergeability, and ruleset requirements. Recheck any status after new commits.

Review correctness, security, test evidence, backward compatibility, migrations, observability, rollback, docs, cost, and permissions. For each finding provide stable ID, severity, file/line or API evidence, impact, remediation, and verification. Separate Copilot/Codex/Claude suggestions from confirmed findings.

Never approve, merge, auto-merge, close, or push merely because checks are green. Copilot-generated changes receive the same human review as any contribution. If addressing comments, collect all in-scope comments before editing and reply only with evidence-backed resolution.
