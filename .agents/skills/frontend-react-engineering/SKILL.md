# Frontend and React Engineering

Inspect the framework, routing, state model, data fetching, styling, accessibility checks, build pipeline, and existing component conventions. Preserve server/client boundaries and avoid introducing global state or a new library without need.

Model loading, empty, error, retry, unauthorized, optimistic, and offline states explicitly. Use stable component contracts, semantic HTML, keyboard support, focus management, labels, and useful error feedback. Avoid leaking sensitive data into URLs, client bundles, logs, or persisted browser storage.

Validate with focused component tests and Playwright for important journeys. Check bundle and rendering impact when relevant, but do not optimize without evidence.
